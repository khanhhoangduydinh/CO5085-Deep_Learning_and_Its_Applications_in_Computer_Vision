Shared experiment rules

Same split, honest selection.

E1-E3 share the same Fashion-MNIST split. A1 uses 400 training and 100 validation images from each CIFAR-100 fine class, then evaluates the validation winner once on the untouched official test set. Results show actual executed runs, not estimated scores.

Reproduce the submission

Run one command per deliverable.

Install the packages in requirements.txt. Fashion-MNIST or CIFAR-100 downloads on the first run, and generated figures are saved under reports/.

python -m E1.run_e1
python -m E2.run_e2
python -m E3.run_e3
python -m A1.run_a1
