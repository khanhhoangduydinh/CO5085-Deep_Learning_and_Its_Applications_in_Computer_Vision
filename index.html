Shared experiment rules

Same split, direct comparison.

The official training set is split once into 48,000 training and 12,000 validation images. Each exercise uses the same final 10,000-image test set. Results show actual executed runs, not estimated scores.

Reproduce the submission

Run one command per exercise.

Install the packages in requirements.txt. Fashion-MNIST downloads on the first run and generated figures are saved under reports/.

python -m E1.run_e1
python -m E2.run_e2
python -m E3.run_e3
