# CO5085 E1-E3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native implementation in this session). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver one simple, reproducible Fashion-MNIST implementation for CO5085 exercises E1, E2, and E3, with an evidence-based report and GitHub Pages links.

**Architecture:** `common.py` owns the fixed Fashion-MNIST split and the explicit PyTorch train/evaluate loops. Each exercise owns only its model definitions and experiment sequence, writes a compact JSON summary, and exports figures that the report and static page render.

**Tech Stack:** Python, PyTorch, Torchvision, Matplotlib, Seaborn, scikit-learn, static HTML/CSS, LaTeX.

**Spec:** `docs/superpowers/specs/2026-10-28-co5085-e1-e3-design.md`

## Global Constraints

- Use Fashion-MNIST only, with seed 42 and a 48,000/12,000/10,000 train/validation/test protocol.
- Keep the official test split out of model and epoch selection.
- Use explicit PyTorch training loops; do not use high-level trainer APIs.
- Use simple functions and small models suitable for a beginner.
- Do not invent reported metrics: the report uses artifacts generated by the scripts.

## Review Focus

- The same split indices must be recreated for all exercises.
- Manual attention must not call `nn.MultiheadAttention`.
- E2 comparison must include manual-versus-PyTorch MSA on patch tokens and a second tokenization.
- E3 must include both LSTM and GRU and reuse the E1 CNN as the non-recurrent baseline.
- The static page and PDF must reference existing files after the scripts run.
