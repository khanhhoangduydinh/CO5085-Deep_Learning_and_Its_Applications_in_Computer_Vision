Shared experiment protocol

Honest splits, zero leakage.

E1–E3 share an identical 48,000 / 12,000 / 10,000 Fashion-MNIST split with fixed seed 42. A1 uses a stratified 40,000 / 10,000 split of CIFAR-100 (400 train, 100 val per fine class), reserving the official untouched 10,000-image test set for the single validation winner. All reported numbers reflect executed runs.

Reproduce the submission

Run locally or on Google Colab.

Install dependencies from requirements.txt. Fashion-MNIST and CIFAR-100 download automatically on first run. Generated metrics and figures are saved under reports/.

# 1. Cài đặt các thư viện
pip install -r requirements.txt

# 2. Chạy bài tập Coursework (Fashion-MNIST)
python -m E1.run_e1
python -m E2.run_e2
python -m E3.run_e3

# 3. Chạy Assignment 1 (CIFAR-100 ResNet-18 vs Swin-T)
python -m A1.run_a1

# 4. Kiểm thử tự động
pytest
