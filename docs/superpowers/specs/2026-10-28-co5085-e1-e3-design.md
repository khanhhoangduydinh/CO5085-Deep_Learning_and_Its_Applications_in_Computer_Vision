# CO5085 E1-E3 Design

## Intent

Create one beginner-readable CO5085 submission that implements every required
experiment in `exercise-vne.pdf`: E1 image classifiers, E2 self-attention and
tokenization, and E3 recurrent image classifiers. The repository also contains
a shared PDF report and a small GitHub Pages index that links the source code
and report.

## Dataset decision

Fashion-MNIST is used for all three exercises. It is one of the datasets
explicitly allowed by the exercise sheet, has 28 by 28 grayscale images and 10
classes, and is small enough for a laptop or Google Colab. The official
60,000-image training split is divided into 48,000 training and 12,000
validation images with seed 42. The official 10,000-image test split is never
used to choose a model or an epoch.

## Approaches considered

1. **MNIST with very small models:** simplest code, but less useful visually
   because digits are much easier than clothing classes.
2. **Fashion-MNIST with small PyTorch models:** selected. It keeps the data and
   code simple while making CNN, attention, and sequence-model errors easier to
   discuss.
3. **CIFAR-10:** valid, but RGB input makes the beginner implementation and
   training time larger without being needed for E1-E3.

## Scope

- E1 implements a flattened softmax classifier, a flattened MLP, and a small
  CNN with explicit `forward -> loss -> backward -> optimizer.step()` loops.
- E2 implements multi-head self-attention once from Linear/matrix operations
  and once with `nn.MultiheadAttention`; it compares patch tokens and CNN-stem
  tokens.
- E3 implements both `nn.LSTM` and `nn.GRU`, reading each 28-pixel image row
  as one sequence step, and compares them with the E1 CNN baseline.
- Every exercise writes JSON results and independent PNG figures under
  `reports/`.
- The shared LaTeX report uses only generated measurements and figures.

## Non-goals

- No pretrained model, transfer learning, high-level training framework, or
  extra dataset is added.
- No result is selected using the official test split.
- The code does not try to be a reusable deep-learning library; clear beginner
  functions are preferred over framework abstractions.

## Architecture

`common.py` contains the small shared data loader, explicit training/evaluation
loops, plotting helpers, and JSON writing. Each exercise keeps its model
classes and experiment list inside its own runnable file:

- `E1/run_e1.py` -> `reports/e1_results.json` and E1 figures.
- `E2/run_e2.py` -> `reports/e2_results.json` and E2 figures.
- `E3/run_e3.py` -> `reports/e3_results.json` and E3 figures.

The report and Pages index only display files produced by those scripts. This
keeps code, reported results, and published artefacts consistent.

## Acceptance criteria

1. The same Fashion-MNIST split and seed are used in E1, E2, and E3.
2. E1 trains and compares softmax, MLP, and CNN with metrics, parameter counts,
   curves, a confusion matrix, and wrong-image examples.
3. E2 has a manual MSA implementation that does not call
   `nn.MultiheadAttention`, a PyTorch MSA comparison using the same patch
   tokens, and a CNN-stem token variant.
4. E3 trains both LSTM and GRU from row sequences and compares their metrics,
   parameter counts, and learning curves with the E1 CNN result.
5. The report explains all models in simple language, uses real generated
   numbers, and compiles without unresolved references.
6. The repository has a README, requirements, Pages links, and is pushed to a
   dedicated GitHub repository.
